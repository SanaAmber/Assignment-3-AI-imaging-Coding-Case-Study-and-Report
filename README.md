# Synthetic Stained-Nuclei Dataset (Biomedical Image Analysis assignment)

A small, self-contained **fluorescence-microscopy nuclei** dataset in the spirit of the
2018 Data Science Bowl set (images **and** ground-truth masks), created for the
Biomedical Image Analysis assignment. It is **fully synthetic**, so it can be
distributed to students without licensing constraints, and every image has an exact,
known ground truth — which makes it ideal for an assignment with an answer key.

## Contents
```
nuclei_dataset/
  train/  images/*.png  masks/*.png  labels/*.png   (80 pairs)
  val/    images/*.png  masks/*.png  labels/*.png   (20 pairs)
  test/   images/*.png  masks/*.png  labels/*.png   (12 pairs, treat as "unseen")
  test_corrupted/images/*.png                        (blurred / low-contrast variants)
  metadata.csv          ground-truth per image (n_objects, density, intensity, ...)
  dataset_summary.json
```
* **images** — 256x256 RGB, DAPI-like blue-stained nuclei on a dark field.
* **masks** — binary PNG (0 = background, 255 = nucleus).
* **labels** — 16-bit instance labels (each nucleus a distinct integer) for optional instance work.

## Density regimes
Images are drawn from four regimes so the difficulty varies: `sparse`, `normal`,
`dense`, and `clustered` (touching nuclei). Object counts range from 5 to 85 per image.

## Licence
Synthetic data generated by `make_dataset.py` (seeded, reproducible). CC0 / public domain —
use freely for teaching. Regenerate or resize with `python make_dataset.py`.

## Running the submission pipeline

Install the Python packages used by the pipeline:

```powershell
python -m pip install numpy pandas matplotlib requests scikit-image torch
```

Run the complete pipeline from this directory:

```powershell
python pipeline.py --epochs 8 --output outputs
```

The default mode uses a documented fallback so the pipeline remains runnable without a
local model. To run both the direct image descriptions and the numbers-only interpretation
through Ollama, first install and start Ollama, pull the model, then use:

```powershell
ollama pull llama3.2-vision
python pipeline.py --epochs 8 --ollama --model llama3.2-vision --output outputs
```

The generated evidence is saved in `outputs/`: `eda.png`, `validation_panel.png`,
`training_curves.png`, `metric_comparison.png`, `robustness_summary.png`,
`evaluation_metrics.json`, `direct_vlm_example.json`,
`classical_features_example.csv`, `numbers_first_example.json`, `test_records.csv`,
`test_records.json`, `test_evaluation_metrics.json`, and `robustness_records.json`.
The validation panel contains three rows, each showing an input, its ground-truth mask,
and its U-Net prediction. The test metrics report mean Dice and IoU against the held-out
test masks, and `unet.pt` is the checkpoint with the best validation Dice.
